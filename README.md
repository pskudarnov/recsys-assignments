# Задания по рекомендательным системам

Здесь собраны отчёты, код и результаты экспериментов по заданиям. Каждый отчёт лежит в отдельной папке, чтобы следующие работы можно было добавить в этот же репозиторий.

По условиям отбора достаточно выбрать **одно** из двух заданий. В репозитории есть оба; для заявки можно дать прямую ссылку на отчёт выбранного задания.

## Задание 1. Автоматический подбор признаков

[Читать отчёт](task-1/README.md) · [Условие задания](task-1/assignment.md) · [Код эксперимента](task-1/experiment.py)

Сравнил ручные признаки и автоматический подбор временных окон на данных KION. В отчёте описаны задача, разбиение по времени, результаты двух запусков, ограничения и шаги для воспроизведения.

## Задание 2. RL для рекомендаций

[Читать отчёт](task-2/README.md) · [Условие задания](task-2/assignment.md) · [Код эксперимента](task-2/yambda_experiment.py)

На Yambda обучил модель следующего трека и четыре RL-варианта. Прогнозируемая доля прослушивания немного выросла, а Recall@10 снизился. В отчёте объясняю, как изменились точность и прогноз отклика, сколько было повторов и что происходит при выборе пяти треков подряд. В той же папке есть дополнительный опыт на MovieLens.
